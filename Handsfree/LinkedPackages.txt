# One package per line. To link a package, make sure its line is here and not
# commented out. scripts/build_app.sh links a listed package only when it exists
# and `swift build` succeeds for it; otherwise it prints why and the app keeps
# using its own stand-in (Handsfree/Integration/StandIns.swift). HFCore is
# always linked and is not listed here.
#
# When a package is linked, the code behind `#if canImport(<Name>)` in
# Handsfree/Integration/ is compiled. If that code no longer matches the
# package's public API, comment the line out to fall back to the stand-in.
